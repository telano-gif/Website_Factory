# Content Skill

## Purpose
Create concise, persuasive website content that accurately represents the client and fits the approved design.

## Input
`INTAKE.md` + `RESEARCH.md` + `DESIGN_SPEC.md`.

## Produce
`CONTENT.md` containing:
- page-by-page content structure
- headings/subheadings
- body copy
- CTAs
- navigation/footer labels
- forms and required fields
- factual claims mapped to available evidence
- unresolved content placeholders only where genuinely necessary

## Rules
- Never invent facts, numbers, clients, awards, testimonials, capabilities or credentials.
- Prefer clarity and specificity over marketing filler.
- Write for the identified audience and business objective.
- Fit copy to the approved component/layout system rather than forcing long text into visual designs.
- Keep unsupported information explicitly unresolved.

## Complete when
Build has all required page content and knows exactly which information is still unavailable.

## Handoff
`CONTENT_COMPLETE` → Build consumes `CONTENT.md` + `DESIGN_SPEC.md` + prior canonical outputs.
